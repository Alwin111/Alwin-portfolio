Overview

Vanguard is a handheld, battery-powered hardware security platform designed for the bi0s Hardware team — India's premier hardware security student group. It combines a badge, field radio, games console, and live CTF target into a single portable device.

The core idea: build a device that a participant can play with and hack on the same hardware. The CTF system runs directly on the badge, creating a self-contained security challenge environment that doesn't require external infrastructure.

Vanguard is built around the ESP32-S3 microcontroller, chosen for its dual-core architecture, integrated Wi-Fi and Bluetooth, and extensive peripheral support. The device communicates via LoRa for long-range mesh networking and BLE for short-range interactions.

⚡ 4-Level CTF System

Progressive difficulty challenge framework with real-time scoring. Each level introduces new attack vectors — from basic reconnaissance to full protocol exploitation.

📡 LoRa Mesh Network

Long-range device-to-device communication for field operations. Multiple Vanguard units can form an ad-hoc mesh network without external infrastructure.

🔋 Battery Powered

All-day portable operation with an integrated power management system. Smart sleep modes and peripheral power gating maximize field uptime.

🎮 Interactive Display

OLED UI with menus, games, and real-time status monitoring. Provides the primary interface for both normal use and CTF challenges.

Implementation

Hardware Design

The PCB was designed in KiCad with a 4-layer stackup to accommodate the ESP32-S3 module, LoRa transceiver, BLE antenna, OLED display connector, battery management IC, and expansion headers for future modules.

Key hardware decisions:

  • ESP32-S3 — Dual-core 240MHz with integrated Wi-Fi/BLE, sufficient GPIO for peripherals, and hardware crypto acceleration
  • LoRa transceiver — Long-range RF communication for mesh networking in outdoor CTF scenarios
  • OLED display — Low-power visual interface for menus, status, and game rendering
  • Battery management — Integrated charging, protection, and voltage regulation for all-day portable use

Firmware Architecture

Written in C using the ESP-IDF framework with a task-based architecture on FreeRTOS. Each subsystem (display, radio, CTF engine, power management) runs as an independent task with message queues for inter-task communication.
